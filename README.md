# Model Canvas (Splat Board)

Interactive static site for browsing human-scale Gaussian splat models on a draggable 2D board.  
Behavior summary:

- Hover promotes a tile from thumbnail to live splat rendering.
- Click opens the model's editorial cover view (masthead, look, what is worn, measurements); models with several captures switch looks there, and the gallery of looks is one step away.
- Drag pans the board with inertial momentum and exits selection/focus mode.

The app is Astro + one React Three Fiber island (`client:only="react"`), so Three.js only runs in the browser.

## Tech stack

- Astro 5 (`output: 'static'`)
- React 19
- three `~0.170`, `@react-three/fiber` 9, `@react-three/drei` 10 (`<Splat>`)
- zustand 5 for board and interaction state

## Quick start

1. Install dependencies:
	 - `npm install`
2. Start local dev:
	 - `npm run dev`

`predev` and `prebuild` both regenerate the splat manifest automatically.

## Data and asset contract

### Source of truth

- `src/data/model-meta.json` is hand-edited metadata.
- `public/splats/*.splat` are runtime splat assets.
- `public/thumbs/*` are runtime thumbnails.

### Generated file

- `src/data/splat-manifest.json` is generated by `scripts/build-splat-manifest.mjs`.
- Do not hand-edit this file.

### Manifest build rules

- Includes all `.splat` files in `public/splats/`.
- Enforces max file size of **24 MB** per board-tier splat (`.full.*` focus tiers are exempt) (oversized files fail with exit code 1).
- Resolves thumbnail in this order: `.png`, `.jpg`, `.webp`.
- Merges matching metadata entry by `id` (`id` must equal splat basename).
- Logs warnings for missing thumbnails or missing metadata.

## Adding a capture

1. Export each model as `.splat` and place in `public/splats/<id>.splat`.
2. Keep each splat under **24 MB**.
3. Add thumbnail in `public/thumbs/<id>.png` (or `.jpg` / `.webp`).
4. Add or update matching metadata entry in `src/data/model-meta.json`.
5. Run `npm run manifest`.

Keep raw capture/intermediate files outside `public/` (for example in a gitignored source-assets folder). The generated `public/splats/` and `public/thumbs/` files are committed: the hosted build reads them from the repo.

## Source-quality captures (Spark + SPZ)

For a 3DGS `.ply` you want shown at full quality in focus view (e.g. `sam-sitting-v1`):

1. Put the `.ply` in `assets-src/` (gitignored, never shipped — anything in `public/` deploys).
2. Add an entry with `fullSpz: true` to `CAPTURES` in `scripts/import-real-splats.mjs`, then run
   `node scripts/import-real-splats.mjs <id>`. Tune `rotateDeg` / `heightM` against the thumbnail.
3. Add the metadata entry and run `npm run manifest`.

Outputs: a capped board-tier `<id>.splat` + thumbnail (drei, shown on hover), and `<id>.full.spz` —
every gaussian of the untouched source with degree-3 spherical harmonics, encoded by Spark's own SPZ
writer (~9× smaller than the `.ply`, visually lossless). The full tier loads only when the model is
focused and renders through `SparkSplat.tsx` (Spark is lazy-loaded). Board normalization isn't baked
into the SPZ (that would resample SH); it lives in `src/data/splat-transforms.json` and is applied
as the mesh transform at runtime.

Floater cleanup is a `bustCrop` (drop everything below a y-level with a short opacity fade, measured
after `rotateDeg`) plus far-outlier removal; surviving splats stay byte-identical. Avoid opacity or
needle-shape filters on these captures — skin, hair and knit are built from faint, thin splats.

`SparkSplat` composites splats in a separate RGBA16F pass: blending ~1%-opacity layers straight into
the 8-bit canvas rounds them away and leaves green/purple blotches on skin.

## Runtime architecture

- `src/pages/index.astro`: page shell and React island mount.
- `src/components/BoardIsland.tsx`: owns one `<Canvas>`, the cover view and gallery overlays, and motion FX.
- `src/components/Board.tsx`: computes deterministic scattered grid layout, applies pan transform, sets pan bounds.
- `src/components/CharacterTile.tsx`: tile state machine (`thumbnail → loading → live → demoting`) and click/hover behavior.
- `src/hooks/useDragPan.ts`: pointer-driven panning + momentum; no OrbitControls.
- `src/components/CameraRig.tsx`: smooth orthographic zoom between base and focus zoom.
- `src/components/EditorialView.tsx` + `EditorialDriver.tsx`: the cover view a click opens (anime.js), and the model's entrance. Copy comes from `src/lib/editorial.ts`.
- `src/components/SparkSplat.tsx`: source-quality splat pass; cached between changes and drawn at reduced resolution while the figure moves.
- `src/components/MotionFx.tsx`: velocity-driven blur, chromatic split, and scratch overlay.
- `src/hooks/useBoardStore.ts`: global interaction state (`pan`, `dragging`, `activeTileId`, `selectedId`, `panTarget`).

## Performance model

- Single WebGL context.
- `frameloop="demand"` to avoid idle rendering.
- One live splat at a time (`activeTileId` concurrency cap).
- Thumbnail preloading and manual culling behaviors in tile logic.

## Deployment

- Output is fully static (`dist/`).
- Both `vercel.json` and `netlify.toml` configure immutable caching for:
	- `/splats/*`
	- `/thumbs/*`

## Engineer handoff notes

- If models do not appear, check `src/data/splat-manifest.json` exists and IDs match filenames.
- If build fails on assets, check for `.splat` files over 24 MB.
- If panel/focus behavior seems wrong, inspect store fields in `useBoardStore.ts` (`selectedId`, `panTarget`, `isDragging`).
